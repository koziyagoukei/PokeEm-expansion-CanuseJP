# 感染者解放戦の戦闘移行演出

`B_TRANSITION_POKEVIRUS_RELEASE`。ヒトポケルスの赤紫の二重螺旋状の鎖が上から3本、下から4本伸び、中央ですれ違いながら画面を覆う。背景を暗紫色に沈め、20フレーム静止してから全体を黒へフェードし、通常の戦闘画面へ渡す。伸長は56フレーム、前段は既存の共通バトル移行イントロを使用する。

## イベントからの使用

感染者との戦闘イベントで、通常の `trainerbattle_single` の代わりに次を使用する。

```text
trainerbattle_pokevirus TRAINER_EXAMPLE, IntroText, DefeatText, PostBattleScript
```

引数は既存の `trainerbattle_single` と同じ。通常の会話・既に倒したかの判定・戦闘後イベント・敗北処理を再利用し、今回の1戦だけ専用の移行演出を選ぶ。通常トレーナー、フロンティアの抽選、通信戦の開始処理は変更しない。低レベルの `trainerbattle` でも末尾の名前付き引数 `pokevirusRelease=TRUE` を使用できるため、2人相手のイベント等にも利用可能。

識別用の一時フラグはセーブされない。トレーナー設定の初期化でクリアし、移行演出選択時にも消費するため、倒した相手との会話等で戦闘が発生しなくても、次に設定した別のトレーナーへ持ち越さない。トレーナー情報・通信データ・セーブ構造のサイズは変更していない。

この演出を選ぶトレーナー戦では専用BGM `MUS_POKEVIRUS_RELEASE` を再生する。心音から始まる曲のため、鎖演出から独立した効果音は鳴らさない。楽譜と再生成・試聴方法は `tools/pokevirus_music/README.md` を参照。

現在のリポジトリには感染者解放戦の対戦相手・開始イベント自体はまだないため、既存のNPCや通常のバトルへは適用していない。

## 描画・素材

`chain.png` は32x64、4bit indexed、透明インデックス0。鎖本体は中央の細い部分で、外側はGBAが扱える縦長OBJの寸法に合わせた透明余白。既存ポケウイルスと共通の色調を使用する。

7本それぞれを3個のOBJで描画するが、画像タイル1024バイトと16色パレット1個は共有する。完全に画面外のOBJは非表示にし、Y座標の折り返しで反対側へ現れることを防ぐ。21個のOBJ・画像タイル・パレットの確保に失敗した場合は、途中まで確保した分を解放し、通常の黒フェードで戦闘へ進む。既存のマップ用スプライトは破棄しない。

画像原画は内蔵 `image_gen` で生成し、`source/chain_generated.png` に保存。`prepare_assets.mjs` の `prepareAssets(PNG, directory)` に `pngjs` と本フォルダを渡すと、最近傍縮小と共通16色化でゲーム用PNG・8倍プレビュー・`validation.json` を再生成できる。半透明や画像ライブラリのゲーム本体依存は追加しない。

生成指示: 既存ポケウイルスを配色と鎖のモチーフの参考にし、顔や本体を描かず、暗い赤紫・黒紫の輪状の節と少量の黄緑の毒色を持つ縦向きの二重螺旋の鎖を1本生成する。GBA世代の硬いドット輪郭、限定色、透明背景。文字・発光・ぼかし・アンチエイリアスを入れない。
