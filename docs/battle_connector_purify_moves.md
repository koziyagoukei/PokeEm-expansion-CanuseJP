# バトルコネクターのリライブ技

バトルコネクターで保護したダークポケモンは、リライブすると下の 2 つの技のうち 1 つを覚える。どちらになるかは個体ごとに
決まっていて（性格値）、持ち帰る 1 匹を選ぶ画面で確かめられる。技がいっぱいなら、リライブの演出の中で忘れる技を選ぶ。

- どの技も、その種族がレベル・わざマシン・教え技・タマゴ技・フロンティアの教え技では覚えない技。
- 部屋に出るのはバトルフロンティアの個体のうち第 1〜3 世代のポケモン（伝説・幻を除く）。部屋の欄は種族値の合計で
  分けた出る部屋（ふつう: 480 未満、強い: 480〜534、めずらしい: 535 以上）。準伝説は中ボスとして出る。
- メタモンとドーブルはリライブ技が無い（へんしん・スケッチの印象を崩さないため）。
- データは `src/data/shadow_purify_moves.h`（ボスは `src/data/shadow_pokemon.h` の各行）。
