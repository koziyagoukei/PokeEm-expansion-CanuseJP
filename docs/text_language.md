# テキストの表示言語

## 基本仕様

この日本語向け基盤では、日本語フォントをデフォルトにしています。

| 文字列の先頭 | 表示モード |
| --- | --- |
| 指定なし | 日本語 |
| `{JPN}` | 日本語 |
| `{ENG}` | 英語 |
| `{AUTO}` | 続く文字・展開先を基に判定 |

```c
const u8 gText_Example[] = _("こんにちは");
const u8 gText_ExistingExample[] = _("{JPN}こんにちは");
const u8 gText_EnglishExample[] = _("{ENG}HELLO");
const u8 gText_MixedExample[] = _("こんにちは {ENG}HELLO{JPN} またね");
```

イベントスクリプトの `.string` でも同じ指定が使えます。

```asm
Example_Text_Greeting:
	.string "こんにちは\nげんきですか？$"

Example_Text_English:
	.string "{ENG}HELLO!$"
```

既存の `{JPN}` は有効なままです。今回の移行では、既存文字列からの一括削除は行っていません。そのため、接頭辞の削除によるROM容量削減も今回の変更には含みません。

## 混在テキストと変数

`{ENG}` / `{JPN}` は、別の指定が現れるか、その文字列の描画が終わるまで有効です。英語部分を挿入した後に日本語へ戻す場合は `{JPN}` を付けます。

```c
const u8 gText_VariableExample[] = _("{STR_VAR_1}{JPN}を えらんだ！");
```

変数内に言語切り替えがあると、その切り替えは展開後の本文にも引き継がれます。変数の終端で、呼び出し元のモードへ自動的に戻る仕組みではありません。英語本文に日本語の名前を挿入する場合など、必要に応じて変数の後に `{ENG}` を指定してください。

`ConvertInternationalString()` が日本語名に付ける終端のモード指定は、デフォルト言語に戻すようにしています。従来と同じバッファ容量で、日本語名の後の本文だけが英語になってしまう問題を避けます。保存データの形式や言語IDは変更していません。

## 記号と自動判定

この変更はフォントの選択方法を変えるもので、文字コードの割り当てを変えるものではありません。`charmap.txt` とフォントPNGは変更していません。

- ひらがな・カタカナは、これまでどおりゲーム内の1バイト文字コードへ変換されます。
- 英語フォント固有の記号・アクセント文字を使う場合は、明示的に `{ENG}` を指定してください。同じバイトが日本語では仮名を表す場合があります。
- `EMOJI_XXXX` や拡張記号は通常のASCII文字とは別で、対応する拡張記号側のグリフを使います。
- ボタンアイコンは従来のアイコン画像を使います。
- `{AUTO}` はデフォルトへ戻す指定ではありません。次の文字などからモードを選ぶ既存の判定です。数字や記号から始まる日本語には、無指定または `{JPN}` を使ってください。

無指定の英語文字列も日本語モードで表示されます。英語モードの字幅を前提とする未翻訳テキスト、数値表示、特殊記号などは、必要に応じて個別に `{ENG}` を付けてください。すべての画面の表示幅を自動調整する変更ではありません。

## 設定と実装

`include/config/text.h`:

```c
#define TEXT_JAPANESE_BY_DEFAULT TRUE
```

`FALSE` にすると、無指定の文字列を先頭の文字などで判定する従来方式に戻せます。`FALSE` は英語固定を意味しません。どちらの設定でも `{JPN}` / `{ENG}` / `{AUTO}` は使えます。

共通処理は `src/text.c` にあります。`IsJapaneseTextMode()` を描画開始と `GetStringWidth()` の両方で利用し、モード切り替え・変数・制御コードを考慮して幅を計算します。日本語の7px送りなど、既存のフォント設定は維持しています。

制御コードの引数に言語切り替えや終端と同じバイト値が含まれていても、通常の文字として誤解釈しないようにしています。

## 確認方法

```sh
python3 -m unittest discover -s tools/tests -p test_text_language_mode.py -v
python3 tools/check_jp_text.py
make -j4 --output-sync=target
```

回帰テストはホストCコンパイラを使い、実際の描画処理・幅テーブル・グリフ選択処理を実行します。VRAMへの書き込みなどのハードウェア部分は代替しているため、画面の見た目の確認は別途必要です。

ゲーム内では、接頭辞なしの会話、既存の `{JPN}` 付き会話、`{ENG}` の英語表示、主人公名・ニックネームの挿入、数字・記号、メニューの位置と改行を確認してください。
