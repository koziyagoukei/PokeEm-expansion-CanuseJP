# 漢字フォント試作

この文書は最初の25字試作の記録です。現在は使用漢字をビルド時に自動登録・生成します。導入方法、最大2,214字のバンク方式、保存・通信向け検査、制約は **[漢字の自動検出とフォント生成](kanji.md)** を参照してください。下記の25字PNGは表示互換の比較基準として残しています。

初期試作は表示確認用でした。現在は表示文字列で使用できますが、バイト数指定の切り詰めや既存のマルチバイト文字列関数ではコードが途中で切れる制約が残ります。保存・通信に入る文字列への漢字使用は引き続き非対応です。

## 対応文字と使い方

最初の試作では戦闘で使う語を中心に次の25字を登録しました。現在もこの25字のIDと字形を維持しています。ひらがな文章の漢字変換は行いません。

```text
攻 撃 防 御 特 性 技 力 速 命 中 状 態 異 常
回 復 対 戦 相 手 物 理 変 化
```

`{KANJI}攻撃と ぼうぎょ` のように記述できます。`{KANJI}` は日本語モードを選び、漢字そのものは `FC 1F xx` の3バイトで各グリフを指定します。そのため漢字の後に `{JPN}` を挟まなくてもかなと混在できます。英語に戻す場合は従来通り `{ENG}` を使用します。文字列の保存領域を決める際は1文字3バイトを考慮してください。既存の名前入力や通信仕様は拡張していません。

例えば、デバッグ用イベントのようにUTF-8で記述します。

```asm
Debug_Text_KanjiFontTest:
    .string "{KANJI}{PLAYER}の 攻撃と 防御\n"
    .string "特性と 状態異常を みる$"
```

これは表示確認の例です。既存画面への一括置換はせず、画面幅と文字列の流れ先を確認してください。現在は `charmap.txt` が `charmap_kanji.txt` の永続ID台帳を読み込みます。

## 見た目の確認

漢字は16pxセルに収めた12×12px、文字送り12pxの表示です。かなより広いため、既存の画面にそのまま置換すると収まらない場合があります。デバッグメニューが有効なビルドでは、「べんりきのう」から「かんじフォントテスト」を開き、会話ウィンドウと `INFO_KANJI_FONT_TEST` で混在表示を確認できます。デバッグメニューの設定は `include/config/debug.h` を参照してください。`FONT_BOLD` の特殊な描画経路は対象外です。

会話・情報ビューア以外の戦闘、ステータス、図鑑、技・特性・アイテム説明などは、漢字入りの画面として網羅的には確認していません。実際の文字送り幅と行間を各画面で確認する必要があります。

## 制約

- プレイヤー名、ポケモンのニックネームなど、セーブ・通信に残る文字列への漢字入力は非対応です。既存の保存形式は変更していません。
- 漢字は1字3バイトです。`StringCopyN` や既存のマルチバイト文字列処理では途中で切れる可能性があるため、一般文字列への使用は互換性確認が必要です。
- 制御コードを除去する `StripExtCtrlCodes` と制御コードを無視する文字列比較では、試作の漢字コードを表示文字として保持します。すべての文字列処理が漢字対応済みという意味ではありません。
- 影は右下1pxに生成し、12×12pxを超える部分を切ります。**既存かなフォントの影と完全には一致しません**。
- 漢字追加は現在の自動生成で対応しました。1bpp化、保存・通信への漢字対応、未検証UIの描画検証は引き続き別の課題です。

## フォント生成とライセンス

以下は旧25字PNGの生成方法です。通常ビルドでは `tools/kanji/kanji_gen.py` を使用し、公式TTFから作成した収録済みアトラスを参照します。

比較用に残している25字PNGは `tools/generate_koden12_test_font.py` で KHドット小伝馬町12 を12pxで二値化した試作品です。文字色のマスクを右下1pxへずらした影を生成し、12×12pxからはみ出す部分を切っています。影は、かなの既存の影との完全一致を保証するものではありません。旧PNGの生成には Pillow と fontTools、および別途入手した元TTFが必要です。元TTFか、必要な文字を網羅するTTFサブセットを引数に指定してください。書体名と全字の収録を検証し、フォントを縮小せず全字共通の基準線で配置します。画像範囲外の点があればエラーにします。生成結果はFreeType等のバージョンや環境の影響を受ける可能性があります。

この旧25字画像は [ZeoSeven の公開Webフォント](https://fontsapi.zeoseven.com/904/main/result.css) のサブセットをTTFに変換して生成しました。このサブセットは元の組み込みビットマップを含まないため、原本のドットと完全一致するとは限りません。現在の公式TTF由来アトラスから生成した25字は、旧PNGとのグリフバイト一致を回帰テストで確認しています。TTF本体は同梱していません。
