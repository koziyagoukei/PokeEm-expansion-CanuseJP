# GC Battle 複数戦 PoC

デバッグメニューの「べんりきのう」から、GC Double / GC Triple / GC Rotation (test)
を起動します。相手と味方はテストモードが生成し、元の手持ちとセーブを使わずに試合結果を表示します。
テスト用セーブはリポジトリに置きません。

| 形式 | 味方と相手の枠 | GBA操作 |
|---|---|---|
| Double | L/R | 味方ごとに A で技一覧、A で技、十字キーと A で相手位置 |
| Triple | L/C/R | Doubleと同じ。端のコマンド画面で SELECT を押すと中央とShift |
| Rotation | L/FRONT/R | コマンド画面の L/R で翼を選び、A で技一覧、A でローテーションと技を確定 |

Aで戦闘結果から復帰、コマンド画面のBで降参できます。合法な対象は色で区別します。
Tripleの近接技は端から同じ側の端または中央へ届きます。つばさでうつは距離を無視する検証用の技です。

`src/frontier_gc_battle.c` がポケモン・技・タイプ表を解決し、Battle Request V1を作ります。
GameCubeはパーティ内の個体と出場位置を別に管理し、PP・ダメージ・ひんし・勝敗を計算します。
`STATE_MULTI`（61 B）に位置と個体の対応、HP、PP、合法対象、入力トークンが含まれます。
`ACTION_MULTI`（8 B）はトークンと入力を返します。GBAは結果のIDと個体の範囲を確認します。
複数戦は表示専用です。Singleの適用モードは検証済みの結果に限り、従来どおりHPとPPを反映します。

対応範囲は通常のダメージ技、範囲技、ひんし、勝敗です。交代・控えからの補充、状態異常・能力ランクの効果、
特性・持ち物・天候・成長・報酬は対象外です。プロトコルとテストは `gba-gc-extension` の
`docs/multiformat.md` を参照してください。Phase 3の保存点は
`origin/frontier-gc-battle` の `301396b60b` です。


## 検証結果

- Doubleは通常チームで2ターン勝利、Lv.45の相手を使う「GC Double (strong test)」で2ターン敗北。4行動、Surfの範囲ダメージ、勝敗受理とフィールド復帰を確認。
- Tripleは左端から中央へのShiftを行い、3ターンで勝利。TVで6体とHUDを確認し、結果受理後にフィールドへ復帰。
- Rotationは左・右へのローテーションを技と同時に入力し、5ターンで勝利。結果を受理して切断。
- Phase 2は強制切断後に再接続し、42点すべてキャッシュから再利用。Phase 3は勝利・敗北・キャンセルを確認。
- Singleの勝利後の次戦でPP 19/20を再読出し。「GC Steven (apply HP/PP)」で敗北後、手持ちビューアーでHP 0/301、PP 17/20を再読出し。

Dolphin 2609bの内蔵GBAで、専用プロファイルとコピーしたセーブを使用しました。
複数戦では手持ち・バッグ・フラグ・変数・SaveBlock1のdigestが一致しました。実機は未検証です。


## 控えの補充

「GC Double (reserve test)」は各陣営の先発2体と控え1体を使います。
ひんしで空いた位置があると、次のターン前にGCが合法な控えを提示します。
上下で選び、Aで送り出します。Bで降参できます。
GCは入力トークンと対象位置を照合し、控えが生存していて場に出ていないことを確認します。

この項目はBattle APP V2を使います。結果は表示専用です。従来のデバッグ項目はAPP V1を使用します。
Dolphin内蔵GBAで味方と相手の補充、勝利、フィールド復帰を確認しました。
安定点の `gc-battle-minimal-formats` では、Rotation勝利後の右への通常移動と再入場も確認済みです。


## 任意交代

「GC Double (switch test)」はBattle APP V3を使います。コマンド画面のSTARTで控え一覧を開き、
上下とAで交代先を選びます。Bでコマンド画面へ戻ります。同じターンに先に選んだ控えは、
もう一方の味方の候補から外れます。GCは位置と入力トークンを照合し、通常の技より先に交代を処理します。
試験は表示専用です。補充専用の項目はAPP V2、従来の各形式はAPP V1で利用できます。

DolphinではHP 1のスバメをジュプトルに交代し、3ターンで勝利してフィールドへ戻りました。
交代したスバメのHPとPPは交代時の値を保持し、元の手持ち・セーブは変化していません。


## わるあがき

「GC Double (Struggle test)」はBattle APP V4を使います。
スバメはHP 1で全技のPPが0です。画面のStruggleをAで選ぶと、GCが合法な相手を抽選し、
攻撃と反動を処理します。反動でひんしになったあと、控えを選んで続行できます。
未対応の技にPPが残っている場合は、わるあがきの条件になりません。

Dolphinで反動、補充、2ターンでの勝利とフィールド復帰を確認しました。


## 強制交代

「GC Double (drag test)」はBattle APP V5を使います。スバメのドラゴンテールと
ヌマクローのほえるを選べます。技が成立すると、GCが相手の控えから1体を選び、
対象位置へ送り出します。ドラゴンテールでひんしになった場合は通常の補充になります。
