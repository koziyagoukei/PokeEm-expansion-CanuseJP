# Frontierhackのコンテスト関連の選択統合

## 参照元と範囲

- 移植元: `origin/frontier-hack` の `1311d015821f32ef997922bb06d1eee588b1390d`
- 統合前master: `0963d6bff6b97e6acf53a818be0b1c6187ecd664`
- 共通祖先: `29f2a287f0a4591bceda590463f660475652a91f`

ブランチ全体のマージではなく、コンテストとその依存処理の選択統合です。
Frontierhackの施設ルール、ハブ、別荘、音楽設定、バッグやセーブの構造変更、
追加のプレイヤー向け習得技機能などは取り込んでいません。

## 取り込んだ内容

- コンテストのメガシンカ、ウルトラバースト、Zアピール、テラスタル、ダイマックスの選択・得点・演出。
- ギミックに応じたカットアウェイ描画、相手役や背景・パレットの初期化と後片付け。
- 通常コンテストのNPCプリセット208件、ランク・部門別の追加NPCと戦術的な技選択。
- 通信コンテストの選択ギミック・得点状態の同期。スプライトID等の端末固有情報は共有しません。
- 112技のコンボ項目を更新。利用できるコンビネーションは既存分を含め577組。
- 通常コンテスト優勝のBP報酬（3 / 5 / 7 / 10BP）と、10BPのポロック・バンダナ交換。
- ミナモ会場のBPショップと、日本語のコンテストヘルプ8トピック・21ページ。
- 紹介画像を早く閉じた場合の遅延アニメ中止、画像解放順序の修正。
- トレーナー名・ニックネーム表示時の言語指定と末尾の `{AUTO}` による復帰。

`src/data/moves_info.h` は `contestComboStarterId` / `contestComboMoves` だけを取り込みました。
威力・命中率・PP・優先度・通常戦闘の効果・技説明文は、統合前masterと一致します。

## 日本語表示・既存アセット

`{AUTO}` が引数なし制御コードであること、および制御コード長の登録はmasterに既存でした。
`src/text.c` / `src/string_util.c` / `src/fonts.c` / `charmap.txt` は変更せず、
日本語デフォルトと、数字だけ英語フォントを使う修正を維持しています。

名前の描画専用バッファに言語制御を付け、保存された名前そのものは拡張しません。
コンテスト結果・紹介・絵画のキャプションにも同じ名前変換を使います。

ROMアセット抽出、Makefile、graphicsの検索パスは変更していません。
ロビーの既存オブジェクト・マップ接続・出口・リージョンも保持し、ショップNPCだけを追加しています。

## 移植元との差分

### 通信

移植元の通信全体の互換チェックは、施設・対戦ルール等にも依存するため取り込みませんでした。
代わりに、コンテストだけで既存LinkPlayerの未使用フィールドへ識別子と形式番号を設定します。

- `CONTEST_LINK_PROJECT_ID = 0x4A43`
- `CONTEST_LINK_VERSION = 1`
- 有線はコンテストのlinkType、無線はコンテストactivityのときだけ設定。
- 全参加者の識別子・形式番号が一致した場合だけ、拡張コンテストデータを送信。
- 非対応時は接続を終了し、日本語の案内を表示してイベントへ復帰。
- 通常の交換・対戦のデータや互換判定には、新しい制限を追加しません。

参加者は同じ版のROMを使ってください。旧master、無改造版、Frontierhackとの直接通信は対象外です。
送信レイアウトや同期ルールを変更する場合は `CONTEST_LINK_VERSION` を更新してください。
構造体サイズは静的検査しています。SaveBlockの構造は変更していません。

### 説明メニューと制限フラグ

Frontierhack専用ハブへの案内はミナモ会場向けに変更し、BPショップからヘルプを開けます。
情報ID 0〜5を維持し、コンテスト用IDは6〜14に追加しました。
9項目のメニューに必要な6件単位の表示切替と、ページ・カーソル位置を含む履歴復帰も移植しています。

`FLAG_FRONTIER_ALLOW_BANNED_SPECIES` は移植元と同じ未使用フラグ位置を利用します。
この基盤では通常コンテストのゲスト選出にだけ適用し、既存フロンティア施設の参加判定は変更しません。
プレイヤーはこのNPC選出制限の対象外です。旗を切り替える専用の設定画面は今回追加していません。

### 習得技の検査

## 検証

今回の統合で確認した結果です。移植元の監査資料に記載された件数とは区別してください。

- `make -j4 --output-sync=target`: 成功。
- `python3 tools/check_jp_text.py`: 成功。
- `python3 -m unittest discover -s tools/tests -v`: 119件成功。日本語・数値フォント・アセット抽出を含む既存テスト。
- `python3 tools/export_contest_combos.py --check`: 成功。
- `make -j4 --output-sync=target check TESTS=Contest`: 72件成功。
- `make -j4 --output-sync=target check TESTS="Link audit:"`: 4件成功。
- `git diff --check`: 成功。

ヘッドレスmGBAで、一時セーブを使って次を確認しました。元セーブには書き込みません。

- メガ、ウルトラバーストからZ、専用Z、テラスタル、キョダイマックス、追加NPCのアピール。
- 日本語名、7文字のひらがな名、7文字の英語名を含む計9ケースで、5回のアピール完了とフィールド復帰。
- 英語プレイヤー名の結果画面まで表示し、名前の後の文字列や後続処理が壊れないこと。
- 実際のショップイベントからヘルプを開き、全21ページを表示、選択位置を保持して戻り、ショップへ復帰。
- 実際の購入イベントでにじいろポロックが格納され、BPが100から90になること。
- レックウザの紹介画像を30フレームで閉じ、ピカチュウを再表示して閉じ、画像バッファが解放されること。
- 画面キャプチャ上でメニュー・名前・本文・紹介画像・パレットの大きな崩れがないこと。

EWRAM使用量は226,840バイト、IWRAMは28,576バイトです。
ログと確認画像はGit管理外の `build/reports/frontier_contest/` に保存しています。

実機プレイ、全種族・全ランク・全部門の通しプレイ、実際の複数台での有線・無線接続は未確認です。
通信テストは2〜4人分の受信状態・同期データを再現する自動テストであり、実接続の保証ではありません。
