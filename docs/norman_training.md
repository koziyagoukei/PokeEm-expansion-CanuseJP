# パパと遊ぶ・努力値変更

## 利用方法

- ミニミニキャンプのパパ（センリ）から、その日のおみやげを受け取る。
- もう一度話すと「あそぼうじゃないか！」と誘われる。
- 「はい」でタマゴ以外の手持ち1匹を選ぶ。
- パパがお手本を見せ、ついジムの特訓になってしまう短い寸劇の後、努力値変更メニューへ進む。
- 能力を選んでA、左右で桁、上下で数値を変更する。数値編集中のAは仮保存、Bはその数値の変更を取り消す。
- 最後の「けってい」で6能力をまとめて反映する。「やめる」または一覧でBを押すと、すべての仮編集を破棄する。
- 各能力252、合計510まで。数値の上限は他の能力への現在の配分も考慮する。配分を移すときは先に別の能力を減らす。
- 回数・BP・アイテム消費の制限はない。既存の日替わりおみやげ処理は維持する。

## 安全性

- 努力値はメニューのタスク領域で仮編集し、確定前にはポケモンへ書き込まない。
- 確定時に対象スロット、空きスロット、タマゴ、各能力と合計の上限を再検証し、検証失敗時は一切書き込まない。
- 変更後は既存の `CalculateMonStats()` で能力を再計算する。瀕死のポケモンは瀕死のままとする。
- 寸劇はその場でのエモートとジャンプのみ。通常移動が終わるまで `lock` で待ってから開始し、地形や他のポケモンとの衝突を避ける。
- 新しいセーブ領域、通信データ、常駐EWRAM変数は追加しない。努力値は既存のポケモンデータとして通常セーブされる。
- 通常戦闘・コンテスト・ハブの生成処理は変更しない。

## 変更ファイル（全8ファイル）

1. `data/maps/PartyRoamerPark/map.json`：パパに名前付きlocal IDを付与。
2. `data/maps/PartyRoamerPark/scripts.inc`：誘い、手持ち選択、寸劇、編集入口、終了・中止の会話。
3. `data/specials.inc`：編集メニューを呼ぶspecialを末尾に追加。
4. `include/party_training.h`：編集入口・努力値反映関数の宣言。
5. `src/party_training.c`：仮編集メニュー、上限・対象検証、確定処理。
6. `src/data/resort_tips.h`：キャンプのTIPSに説明ページを追加。
7. `test/party_training.c`：対象・上限・能力再計算等のテスト5件。
8. `docs/norman_training.md`：本資料。
